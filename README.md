# Portafolio de Mapas

Plataforma de mapas interactivos para el análisis territorial, laboral y económico del estado de Yucatán.

---

### 🗺️ Mapas Disponibles

* **Índice de Necesidad Prioritaria**  
  Identifica los municipios con mayor necesidad de atención para la generación de empleo, considerando indicadores sociales, laborales y económicos.

* **Población Desocupada por Municipio**  
  Porcentaje de la Población Económicamente Activa (PEA) que se encuentra desocupada en cada municipio de Yucatán.

* **Empresas Grandes en Yucatán**  
  Ubicación territorial de las grandes empresas de Yucatán.
